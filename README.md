Sistema de Ingressos para Cinema
Sistema de venda de ingressos para cinema desenvolvido em Java, aplicando conceitos de Programação Orientada a Objetos (POO), como herança, polimorfismo e encapsulamento.

Funcionalidades
Venda de ingresso normal
Venda de meia-entrada
Venda de ingresso família
Cálculo automático de descontos
Seleção de idioma do filme (Dublado ou Legendado)
Interface interativa utilizando JOptionPane
Formatação de valores em Real (R$)
Regras de Negócio
Ingresso Normal
Valor fixo de R$ 30,00
Meia Entrada
50% de desconto sobre o valor do ingresso
Valor final: R$ 15,00
Ingresso Família
Valor calculado com base na quantidade de pessoas
Desconto de 5% para grupos com mais de 3 pessoas
Exemplo de Cálculo
Valor do ingresso: R$ 30,00

Grupo com 4 pessoas:

Valor sem desconto: R$ 120,00
Desconto (5%): R$ 6,00
Valor final: R$ 114,00
